  # OmegleApp

A real-time video chat application inspired by Omegle. Built using WebRTC, Socket.io, and Node.js.

## Features
- Anonymous video chat
- Real-time communication
- Secure and scalable

## Tech Stack
- Node.js
- Express.js
- Socket.io
- WebRTC
- HTML/CSS/JavaScript

## Setup

```bash
npm install
node server.js
